## Convención de vigencia

Los índices separan el material en: **contrato vigente verificado**, **implementación documentada**, **histórico** y **pendiente de validación**. Un documento cuya vigencia no se ha verificado no se marca como vigente. Los documentos históricos llevan al inicio una nota de **Estado documental** con su fecha de corte original.
